📋 Project Overview

The Prop MT5 Connection Service is a robust, production-ready Windows Service that provides RESTful API endpoints for managing MetaTrader 5 (MT5) trading accounts, executing trades, monitoring positions, and performing automated liquidation checks.

🔌 MT5 Integration

Direct connection to MetaTrader 5 servers using official MT5 Manager API

🔄 Real-time Operations

Live account management, trading operations, and market data access

⚡ High Performance

Optimized for high-frequency operations with caching and monitoring

🛡️ Production Ready

Enterprise-grade security, logging, error handling, and monitoring

Technology Stack

.NET Framework 4.8 C# 7.3 OWIN ASP.NET Web API Nancy Framework Serilog Entity Framework Topshelf MetaTrader 5 API

💰 Liquidation Management

GET /api/liquidation/MT5Liquidation?accountId={id}

Check and perform liquidation on accounts based on risk parameters

Parameters:
accountId (optional): long - Specific account ID or 0 for all accounts
Response:
{ "success": true, "message": "Liquidation check completed successfully", "data": { "accountsChecked": 150, "accountsLiquidated": 3, "timestamp": "2025-01-13T10:30:00Z" } }

🚀 Quick Start Guide

1. Testing the API

curl http://localhost:8086/health curl http://localhost:8086/api/health curl http://localhost:8086/api/mt5/accounts

2. Creating an Account

curl -X POST http://localhost:8086/api/mt5/account/create \ -H "Content-Type: application/json" \ -d '{ "userId": 12345, "name": "John Doe", "email": "john@example.com" }'

3. Checking Liquidations

curl http://localhost:8086/api/liquidation/MT5Liquidation

⚙️ Configuration

Service configuration is managed through appsettings.json:

{ "WebServer": { "BaseUri": "http://localhost:8086" }, "MT5": { "Live": { "Server": "37.27.232.54:1950", "Login": 1000, "Password": "********" } }, "BackgroundJobs": { "LiquidationCheckIntervalSeconds": 3600 } }
