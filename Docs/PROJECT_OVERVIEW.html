📋 Project Overview

The Prop MT5 Connection Service is a robust, production-ready Windows Service that provides comprehensive RESTful API endpoints for managing MetaTrader 5 (MT5) trading operations. Built with enterprise-grade architecture, this service enables seamless integration between your trading platforms and MT5 servers, offering real-time account management, trade execution, performance monitoring, and automated risk management capabilities.

🎯 Purpose

Provides a unified API layer for MT5 trading operations, enabling proprietary trading firms to manage accounts, execute trades, monitor positions, and implement automated risk controls through a modern REST API.

👥 Target Audience

Proprietary trading firms, forex brokers, trading platforms, algorithmic traders, and financial technology companies requiring programmatic access to MetaTrader 5 operations.

🔑 Key Benefits

Real-time trading operations, automated risk management, comprehensive account analytics, scalable architecture, production-ready logging, interactive API documentation, and enterprise-grade security.

📊 Current Status

Production Ready - Fully functional with comprehensive API documentation, health monitoring, automated liquidation, and real-time position tracking. Actively maintained and deployed.

🚀 Getting Started

1️⃣ Prerequisites

• Visual Studio 2019 or later
• .NET Framework 4.8 SDK
• MetaTrader 5 Manager API DLLs
• PostgreSQL Server (optional)
• Access to MT5 trading server

2️⃣ Clone Repository

git clone https://github.com/chiragkevadiya/prop-mt5-service.git

3️⃣ Configure Application

• Update appsettings.json with MT5 server details
• Configure database connection strings
• Set up SMTP settings for email notifications
• Configure logging preferences

4️⃣ Build Solution

• Open solution in Visual Studio
• Restore NuGet packages (Ctrl + Shift + B)
• Build solution (F6)
• Verify no build errors

5️⃣ Run Application

• Press F5 to start debugging
• Service starts on http://localhost:8086
• Open browser and navigate to welcome page
• Verify health check endpoint responds

6️⃣ Install as Windows Service

PropMT5ConnectionService.exe install
PropMT5ConnectionService.exe start

7️⃣ Access Documentation

• Swagger UI: http://localhost:8086/docs
• API Explorer: http://localhost:8086/explorer
• Test endpoints and explore API
