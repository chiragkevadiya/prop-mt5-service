? Key Features

??

Account Management

Full lifecycle management of MT5 trading accounts � create, update, delete, activate/deactivate, password changes, leverage updates, and group assignments for both Live and Demo servers.

??

Trading Operations

Open/close positions, view trade history, credit in/out, withdrawal processing, terminal-to-terminal transfers, and real-time open trade details through the MT5 Manager API.

??

Prop Trading Challenges

Challenge phase tracking, settlement processing, daily equity history, and automated evaluation to manage proprietary trading challenge workflows.

??

Auto-Liquidation Engine

Background service that periodically checks account positions against risk rules and automatically liquidates accounts that breach thresholds � running every 30 seconds via a background task.

??

Leaderboard & Analytics

Real-time leaderboard rankings, profit-by-symbol reports, daily profit charts, account performance metrics, and live dashboard summaries for trading analytics.

??

Email Notification System

Template-based email system with variable substitution, attachment support, and logging � used for trade notifications, challenge updates, and account alerts.

?? Service Lifecycle

?? Startup Flow

  1. Program.cs � Topshelf bootstraps WebServer as a Windows Service
  2. WebServer.Start() � Launches OWIN host on http://localhost:8086
  3. Startup.Configuration() � Configures middleware pipeline, Web API routes, DI, file server, and Nancy
  4. ClientConnect.Initialize() � Initializes MT5 Manager API factory & creates live manager
  5. ClientConnectDemo.Initialize_demo() � Creates demo manager
  6. ClientConnect.Connect() � Connects to live MT5 server (37.27.232.54:1950)
  7. Background Task � Starts liquidation monitor loop (every 30s�1hr)

?? Shutdown Flow

  1. WebServer.Stop() � Cancellation token signals background tasks
  2. Background liquidation task completes current iteration
  3. OWIN web application is disposed
  4. Topshelf handles clean service shutdown
